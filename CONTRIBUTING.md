# Contributing

This is a static interview-prep desk. Please keep it that way.

1. Read [AGENTS.md](AGENTS.md) for the product contract.
2. To add a problem, follow [skills/add-problem/SKILL.md](skills/add-problem/SKILL.md).
3. Create a branch. Do not commit to `main`.
4. Run `./serve.sh` and click through the page you changed, including the figure and the revealed solution.
5. Push the branch and open a pull request into `main`.
6. Do not commit `.vercel`, editor junk, or secrets.

Pull requests should say which answers you derived and how you checked the figure.
Do not merge unless the owner asks you to.
